# Flight Orbit 3D Card

A live, pitched 3D aircraft map for Home Assistant using the FlightRadar24 integration as its data source.

## Highlights

- Actual aircraft altitude above 3D terrain
- Satellite and dark basemaps
- Heading-correct aircraft symbols
- Smooth movement between Home Assistant updates
- Flight trails from coordinate history
- Focus, follow, orbit and fullscreen controls
- Airport ground-vehicle filtering
- Callsign, route, aircraft, altitude, speed and vertical-speed details
- Emergency squawk highlighting when the integration supplies squawk data

The card reads Home Assistant entity attributes locally. It does not make additional FlightRadar24 API calls.
